# 分应用代理

在「工具 → 分应用代理」中启用。列表按应用包名匹配，应用名称只用于显示。

- **白名单**：只有勾选的应用进入 VPN，未勾选及未添加的应用直连。适合只想让少数应用使用 VPN 的情况。白名单启用时必须至少勾选一个应用。
- **黑名单**：勾选的应用绕过 VPN、直接联网，其余应用进入 VPN。适合只想排除少数应用的情况。名单为空时不排除任何应用。
- **关闭分应用代理**：不按应用筛选，所有应用依照系统 VPN 路由接管。

“进入 VPN”表示应用流量交给 LexiClash 内核。最终走代理节点还是直连，仍由规则、全局或直连模式决定。例如：白名单勾选浏览器后，浏览器进入 VPN，但在规则模式下，匹配 DIRECT 的请求仍会直连。

## 添加和应用

1. 填写设备中已安装应用的准确包名，例如 `com.example.app`，可填写便于辨认的应用名称，然后点击「添加并勾选」。示例包名只是格式说明。
2. 选择白名单或黑名单，勾选需要纳入名单的应用。支持搜索、取消勾选和移除，最多添加 256 项。
3. 设置会自动保存在本地；VPN 未连接时，在下次连接时生效。
4. VPN 已连接时，页面会标记未应用的修改，点击「应用并重连」重新创建系统 VPN。此操作短暂中断连接，同时保留当前的代理选择和代理链。

删除或取消勾选最后一个白名单应用后，需要添加应用或关闭分应用代理才能重新连接。无效或空白名单不会替换当前运行中的 VPN。绕过 VPN 的应用，其流量和 DNS 不经过 LexiClash，因此也不受内核防泄露设置保护。

## 获取应用包名

在目标应用内截图，然后在图库详情或文件管理器中查看截图完整文件名。文件名的最后一部分就是应用包名，去掉图片扩展名后填写到 LexiClash。例如，截图名以 `_com.example.app.png` 结尾时，包名为 `com.example.app`。

请使用目标应用正常页面的截图。系统 VPN 始终使用 TUN，连接后按分应用名单接管流量。

## 鸿蒙手机的应用列表限制

当前通过手动填写包名维护列表，并校验包名格式。应用内无法确认该包名对应的应用是否已安装，必须填写真实、准确的包名；未安装或拼错的包名不能匹配目标应用。

普通手机应用不能通过公开的包管理 API 枚举所有已安装应用。系统权限接口不适用于普通应用；API 26.0.0 的 `getInstalledBundleList` 需要 `ohos.permission.ENTERPRISE_GET_INSTALLED_BUNDLE_LIST`，并且仅在 PC/2in1 上支持。本实现不申请这些额外权限。

参考：[华为包管理 API](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-bundlemanager/)、[华为 VPN 配置 API](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-net-vpnextension/)。白名单对应 `trustedApplications`，黑名单对应 `blockedApplications`，两者不会同时配置。

## 真机验收

准备两个可独立访问网络的已安装应用 A、B，以及可正常工作的代理配置。在全局模式下，按以下顺序检查各应用的出口 IP；更改策略后重新启动目标应用或关闭其旧连接，以免复用先前建立的连接。

1. 关闭分应用代理：A、B 都按 VPN 路由处理。
2. 白名单只勾选 A：A 使用代理出口，B 使用本地网络出口。
3. 黑名单只勾选 A：A 使用本地网络出口，B 使用代理出口。
4. 黑名单取消所有勾选：A、B 都按 VPN 路由处理。
5. 保持 VPN 连接，修改名单但不应用：原策略继续生效；点击「应用并重连」后使用新策略。
6. 重启 LexiClash：模式、启用状态、所有列表项和勾选状态应保留。
7. 验证空白名单无法启动、IPv4/IPv6 均按应用筛选，以及已有代理链在应用设置后仍能连接。

主机回归测试使用模拟的系统 VPN 接口，验证名单传递、持久化、互斥配置、校验和重连流程，不能替代真机网络验收。
